Ubah Style CSS

Kotak di bawah berwarna biru, padahal seharusnya hijau. Cari tahu properti CSS mana yang mengatur warnanya.

i

Panduan dasar: warna tampilan

Masalah: kotak masih biru, tujuan di bawah minta hijau.
Yang dikerjakan: pilih kotaknya, buka panel yang menampilkan tampilannya, cari baris pengatur warna latar, ketik nilai hijau dari kotak Tujuan, tekan Enter.
CSS mengatur tampilan seperti warna, seperti cat pada rumah.
Kesalahan umum: ubah teks bukan warna, ketik kode warna kurang lengkap, lupa tekan Enter.

Warna berhasil diubah ke hijau! Kamu paham cara mengutak-atik CSS lewat panel Styles tanpa menyentuh file.
✓

Pembahasan: background-color

Kode: background-color mengatur cat latar elemen. Analoginya seperti mengganti cat tembok satu ruangan.
Masalah: kotak #style-box masih biru #3b82f6, tujuan minta hijau #16a34a.
Solusi: pilih #style-box, klik nilai background-color di panel Styles, ketik #16a34a, tekan Enter.
Kenapa penting: warna situs diatur terpusat lewat CSS jadi mudah diganti serentak.
Coba lagi: tekan Kembalikan biru, lalu ubah ke hijau tanpa hint.
